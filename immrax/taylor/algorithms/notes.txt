  How the Algorithms Work                                                                                                                                                                                                                   
                                                                                                                                                                                                                                            
  Both solve the same problem: given an ODE ẋ = f(t, x) with interval initial conditions x(t₀) ∈ X₀, compute a rigorous flowpipe (sequence of interval enclosures of the reachable set over time). They share steps 1-2 and differ in step 3
   (validation).                                                                                                                                                                                                                            
                                                                                                                                                                                                                                            
  Shared Steps (per time step)                                                                                                                                                                                                              
                                                                                                                                                                                                                                            
  1. Prolongation: Compute time Taylor coefficients [x, ẋ, ẍ, ..., x^(p)] at the center of the current set using jax.experimental.jet. This gives a polynomial approximation of the trajectory.                                             
  2. Step-size selection: Pick h from the last two Taylor coefficient norms: h = min_k (abstol / ||x_k/k!||)^{1/k}.                                                                                                                         
                                                                                                                                                                                                                                            
  After validation, both evaluate the Taylor polynomial at h and add the validated remainder to form the interval enclosure.                                                                                                                
                                                                                                                                                                                                                                            
  validated_integ — Picard-Lindelöf Iteration                                                                                                                                                                                               
                                                                                                                                                                                                                                            
  Validation strategy: Directly searches for an interval Δx satisfying the contraction mapping theorem (Schauder/Picard-Lindelöf).                                                                                                          
                                                                                                                                                                                                                                            
  - Initializes Δx from a Lagrange remainder estimate: |x^(p+1)| · h^{p+1} / (p+1)!                                                                                                                                                         
  - Iterates the Picard operator: P[Δx] = R₀ + [0,h] · (f(t, x̃ + Δx) − x̃')                                                                                                                                                                  
  - Checks if P[Δx] ⊂ int(Δx) (strict inclusion = contraction)                                                                                                                                                                              
  - If not contractive but P[Δx] ⊆ Δx, widens Δx at touching boundaries by machine-epsilon amounts                                                                                                                                          
  - If P[Δx] ⊄ Δx, expands Δx to contain P[Δx]                                                                                                                                                                                              
  - Also uses a rough enclosure helper for initial bounding                                                                                                                                                                                 
                                                                                                                                                                                                                                            
  validated_integ2 — Epsilon-Inflation (Bünger 2019)                                                                                                                                                                                        
                                                                                                                                                                                                                                            
  Validation strategy: Uses systematic epsilon-inflation of non-contractive components.                                                                                                                                                     
                                                                                                                                                                                                                                            
  - Starts with E = 0 (zero remainder)                                                                                                                                                                                                      
  - 0th iteration: E' = Picard(E) including the initial-condition remainder R₀                                                                                                                                                              
  - Subsequent iterations: E' = Picard(E) without R₀                                                                                                                                                                                        
  - Checks componentwise contractivity E'_i ⊂ int(E_i)                                                                                                                                                                                      
  - For each non-contractive component, inflates: E_i ← E'_i · (1 ± ε) + [-δ, δ]                                                                                                                                                            
  - Contractive components are left unchanged                                                                                                                                                                                               
                                                                                                                                                                                                                                            
  Key Differences                                                                                                                                                                                                                           
  ┌───────────────────┬─────────────────────────────────────────────────────────────────────┬───────────────────────────────────────────────────────────────────────────────────────────────────┐                                           
  │      Aspect       │                           validated_integ                           │                                         validated_integ2                                          │                                           
  ├───────────────────┼─────────────────────────────────────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────────┤                                           
  │ Initialization    │ Lagrange remainder estimate                                         │ Zero remainder                                                                                    │                                           
  ├───────────────────┼─────────────────────────────────────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────────┤                                           
  │ Widening          │ Global: expand Δx to contain P[Δx], widen touching boundaries       │ Per-component: inflate only non-contractive dimensions by (1±ε) + [-δ,δ]                          │                                           
  ├───────────────────┼─────────────────────────────────────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────────┤                                           
  │ Initial remainder │ Always included in Picard                                           │ Only in 0th iteration                                                                             │                                           
  ├───────────────────┼─────────────────────────────────────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────────┤                                           
  │ Parameters        │ None beyond shared                                                  │ epsilon, delta, validatesteps                                                                     │                                           
  ├───────────────────┼─────────────────────────────────────────────────────────────────────┼───────────────────────────────────────────────────────────────────────────────────────────────────┤                                           
  │ Character         │ More conservative; tries 50 Picard iterations with global expansion │ More targeted; inflates only failing components, generally converges faster for non-stiff systems │                                           
  └───────────────────┴─────────────────────────────────────────────────────────────────────┴───────────────────────────────────────────────────────────────────────────────────────────────────┘                                           
  The epsilon-inflation approach (method 2) is typically simpler and more efficient because it only inflates the specific components that fail contractivity, rather than globally expanding the candidate interval. Method 1 is closer to  
  the classical Schauder fixed-point approach.
